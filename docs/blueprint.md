# **App Name**: Eventide Capture

## Core Features:

- Media Capture: Capture photos and videos directly through the app.
- Event Authentication: Join an event by scanning a QR code or entering a code.
- Automated Upload: Automatically upload captured media to the corresponding event's online gallery.
- Web Gallery Display: Display photos and videos in an organized, user-friendly web gallery.
- Live Display: Enable display of selected photos and videos on TVs at the event location.
- Smart Curation: AI-powered tool to suggest the best photos and videos to display on the live TV feed based on visual quality and relevance.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and professionalism.
- Background color: Very light blue (#E8EAF6), nearly white, creating a clean backdrop that lets the media content stand out.
- Accent color: Amber (#FFC107) to draw attention to key actions.
- Font pairing: 'Poppins' for headlines (sans-serif) and 'PT Sans' for body text (sans-serif) to balance modern clarity with readability.
- Use clear, modern icons to represent actions such as 'upload,' 'share,' and 'display'.
- Clean, grid-based layout to showcase photos and videos in an organized manner, both on the app and the website.
- Smooth transitions and loading animations to provide a polished user experience.
